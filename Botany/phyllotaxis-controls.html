Algorithmic Botany — Phyllotaxis

Canvas API Phyllotaxis Procedural

About This App

  • The three buttons allow you to pause, restart and reverse the pattern
  • The pause button stops the app by preventing the loop from running
  • The restart button sets n = 0 again and paints a black box on the canvas to erase the pattern
  • The reverse button subtracts 1 from n each loop and paints a black dot over the dots in the opposite order they were placed
  • Other changes include:
    • Increased frame rate to 60 FPS
    • Increased canvas size to 800×600
    • C value and divergence changed to 2.8 and 144 respectively
